# 📱 SIMU - Social Media Platform

Social Media Platform ya kisasa iliyotengenezwa kwa Java Spring Boot + MySQL + HTML/CSS/JavaScript.

## ✨ Features

- 👤 Usajili na Kuingia (JWT Authentication)
- 📝 Posts (Create, Read, Update, Delete)
- 💬 Comments
- ❤️ Likes
- 👥 Follow System
- 🔔 Notifications
- 🔍 Search
- 🎨 Dark Mode
- 😊 Emoji Picker
- ✏️ Edit Post

## 🛠️ Teknolojia

### Backend
- Java 21
- Spring Boot 4.0.0
- Spring Security (JWT)
- Spring Data JPA
- MySQL
- Maven

### Frontend
- HTML5
- CSS3
- JavaScript

## 🚀 Jinsi ya Kuendesha

### 1. Mahitaji
- Java 21+
- MySQL (XAMPP)
- Maven

### 2. Unda Database

    CREATE DATABASE social_media;

### 3. Endesha

    mvnw.cmd spring-boot:run

### 4. Fungua Browser

    http://localhost:8081/
